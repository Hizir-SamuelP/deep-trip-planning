# 可复制的攻略模板

按行程重心删减章节；不要为了填模板而虚构资料。所有会变的硬信息都附本次来源，或标为“出发前 X 天复核 + 去哪里复核”。

```markdown

- 已订住宿 / 航班 / 预约：
- 每日原点：
- 旅行风格数字：节奏、排队上限、缓冲、预算姿态、确定性偏好
- 入境与健康核验：状态、官方来源、最晚动作日

## 最终选择

## N 天总览

## 交通与地图执行

## 逐日详细路线

## 重点项目的最佳时间与避雷

## 费用总账

## 票务与预订倒计时

## 行李清单

## 应急卡

## 来源说明

## 交付前自检结果
```

## 倒计时表模板

```markdown
| 最晚日期 | 动作 | 依据/来源 | 负责人 | 未完成的后果 |
|---|---|---|---|---|
| YYYY-MM-DD | 签证/电子许可/入境登记复核 | 官方页面 | 旅客 | 可能无法登机 |
| YYYY-MM-DD | 免费取消截止 | 预订确认页 | 旅客 | 产生费用 |
| YYYY-MM-DD | 预约/抢票 | 官方预约页 | 旅客 | 售罄 |
| 出发前 7 天 | 营业、价格、制度、季节窗口复核 | 官方页 | 规划者 | 现场空跑 |
| 出发当天 | 交通与临时公告复核 | 运营方公告 | 旅客 | 误机/绕路 |
```

## 行李清单的生成法

按四个变量生成，不要给所有人同一张清单：

1. **气候与天气**：按预计温度、降雨、日晒、昼夜温差选分层衣物和雨具；临行前按官方预报删减。
2. **活动类型**：徒步、海滩、正式餐、宗教场所、雪地或高风险活动各加入对应鞋服/装备，并核对现场租借和限制。
3. **天数与洗衣条件**：按洗衣频率决定衣物轮换数量，而不是按天数机械翻倍。
4. **托运与随身限制**：把护照、药品、充电、必要换洗和延误第一晚必需品留在随身行李；液体、电池、锂电池和药品按航空公司与目的地规则复核。

攻略里列“必随身 / 必托运 / 可现场买 / 出发前确认”四栏，并把药品、插头、电池和活动装备的规则来源标出。

## 应急卡模板

```markdown
## 应急卡
- 急救：[目的地具体号码]；报警：[具体号码]；旅游/非紧急警务：[具体号码或官方页]
- 最近急诊/医院：[名称、地址、电话、路线]
- 中国/本国使领馆：[名称、地址、24 小时电话、官方链接]
- 误机：[航空公司当地电话、值机柜台/改签入口、最晚到达时间]
- 丢护照：[当地报警流程、使领馆旅行证流程、护照复印件/电子备份位置]
- 支付全部失效：[备用实体卡、紧急现金、发卡行国际电话、可联系的人]
```

不要留“拨打当地急救电话”之类的空话；交付时必须按目的地填具体号码与官方来源。
